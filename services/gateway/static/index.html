Rate-limit policies (IETF draft headers)

6 tiers

Every response emits standard RateLimit-Limit, RateLimit-Remaining, RateLimit-Reset, RateLimit-Policy, and Retry-After on HTTP 429.

Working quick-start examples

Check runtime health & Redis rate-limiter mode:

curl -sS https://api.mikeodnis.dev/v1/core/status

Sign in and upload an asset to cdn.mikeodnis.dev:

JWT=$(curl -sS -X POST https://api.mikeodnis.dev/v1/core/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@mikeodnis.dev","password":"..."}' | jq -r .access_token)

curl -sS -X POST https://api.mikeodnis.dev/v1/media/upload \
  -H "Authorization: Bearer $JWT" \
  -F "file=@./image.png" -F "visibility=public"

Frequently asked questions

How do JSON API clients use the root endpoint?

GET / uses content negotiation: browsers receive this Live Console page, while non-HTML API clients (Accept: application/json or default curl) receive the machine-readable JSON route descriptor.

Can I upload files without writing curl commands?

Yes. Open cdn.mikeodnis.dev/upload (opens in a new tab) (installable PWA on Android and Desktop) to sign in, drag-and-drop, paste screenshots, or share directly from your phone into Cloudflare R2.
